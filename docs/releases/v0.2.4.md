# Veya v0.2.4

修复 CPU 渲染下高 DPI 缩放造成的图标错位和额外放大，针对 2K 屏幕、Windows 125% 缩放时导航与按钮图标偏离原位置的问题。

## 图标与缩放

- 修复 SVG 图标重复应用 DPI 缩放：图标已按物理像素栅格化，呈现时再缩放一次会使位置向右下偏移并扩大尺寸；现在按物理位置直接绘制，只保留旋转。
- 管理窗口和快捷面板共用该修复，覆盖侧栏、内容分类、搜索、复制及其他 SVG 图标。
- 保留按物理像素尺寸生成的图标缓存和旋转中心，避免通过低分辨率图标放大来修正位置。继续使用 `tiny-skia` CPU 渲染。

## 升级与数据

- 可覆盖安装 v0.2.3，历史和设置仍保存在 `%APPDATA%\Veya\veya.db`；安装与卸载保留用户数据。
- 本版没有数据库迁移，不改变记录载荷、固定状态、来源置信度或已有使用线索。
- 快捷键、搜索和按原类型重放的操作方式保持一致。

## 验证

- 新增 6 项回归测试，使用实际 CPU 渲染器检查 100%、125%、150%、200% 下 SVG 的像素位置和尺寸，并检查普通 RGBA 图片、旋转及图层裁剪。修复前 125%、150%、200% 的 SVG 检查失败，修复后通过。
- 通过实际 CPU 渲染器离屏绘制 2560×1440 管理界面及快捷面板；核对 125% 下导航、分类、搜索和复制图标的对齐。
- 本地格式检查、workspace 检查及 129 项测试通过。发布流程在一次性 Windows runner 中重新运行检查、构建 release 安装包，并验证真实安装、覆盖升级、已安装程序哈希／版本、快捷方式、卸载和用户数据保留。
- 临时截图代码已清除，仓库保留正式像素回归测试和补丁维护说明。

## 已知限制

- 高 DPI 证据来自实际渲染器的离屏绘制；本轮未在真实 2K 显示器上验证窗口显示、不同缩放显示器间切换或安装后的桌面交互。
- 保留 v0.2.3 的最小化恢复限制：首幅软件画面提交前可能短暂透出下层内容。
- 安装包未签名，Windows 可能提示未知发布者。
