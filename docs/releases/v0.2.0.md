# Veya v0.2.0

此版本修复窗口拖动、安装器启动后与普通权限截图工具的兼容问题，加入图片大图查看，并改善桌面图标和项目文档。

## 变化

- 窗口左上角品牌区和顶部拖动区域可直接拖动窗口，修复部分机器上拖动无响应的问题。
- 点击历史详情中的图片缩略图或“查看图片”，可打开弹窗放大、缩小并查看图片。
- 安装器完成页启动 Veya 时，程序会尝试以 Explorer 的普通用户权限重新启动，避免提权窗口影响普通权限截图工具的 F3 快捷键。
- 放大图标主体，并让安装器为桌面及开始菜单快捷方式使用独立、按图标内容命名的 ICO 文件，避免 Windows 沿用旧的图标缓存。
- 整理 README，并加入界面截图。

## 升级与数据

- 可直接覆盖安装 v0.1.0；安装器会关闭正在运行的 Veya，然后更新程序和快捷方式。
- 历史与设置继续保存在 `%APPDATA%\Veya\veya.db`，覆盖安装和卸载都不会主动删除该数据库。
- 安装包需要管理员权限写入 Program Files，目前未签名，Windows 可能提示“未知发布者”。

## 验证与限制

- Windows 本机已完成格式检查、workspace 测试与检查、release 编译及 NSIS 安装包构建；GitHub CI 和发布资产以本次发布流程的实际结果为准。
- 已在本机通过覆盖安装确认 Veya 以普通权限运行，桌面图标大小正常。窗口拖动、图片弹窗和 F3 截图在其他机器或应用中的实际交互尚未完整验收。
- “使用记录”只表示观察到粘贴快捷键及当时的前台目标，不能证明目标应用已成功插入内容。文件记录只保存路径，图片捕获覆盖 `CF_DIB` 与 `CF_DIBV5`；其他剪贴板格式可能无法记录。
