# Veya v0.2.2

这个版本让 `Alt+V` 直接打开快捷粘贴面板，并优先加载可操作的最近记录。它同时减少大文本／图片历史的重复读取与内存复制，修复窗口收起后仍可能占满一个 CPU 核心的问题。Windows 中的产品名和文件描述统一简化为 **Veya**。

## 日常使用

- 在输入应用中按 `Alt+V`，直接输入关键词搜索完整历史，上下键选择，按 `Enter` 或点击记录后回到原窗口粘贴。`Esc` 返回原应用，切换到其他窗口时面板收起。快捷键仍可修改或关闭。
- 面板的“管理历史”、系统托盘和再次启动 Veya 打开完整管理窗口，继续查看来源、使用线索、完整内容和设置。
- 粘贴前确认原类型剪贴板写入成功并核对序号；目标窗口消失、焦点切到第三方应用、剪贴板被替换或按键未释放时取消自动粘贴。失效文件或复制失败会显示错误，避免误粘旧内容。
- 内部重新复制仍绑定原始历史记录，不增加 Veya 自己产生的复制记录；使用线索继续表示观察到的粘贴尝试。

## 加载与资源

- 最近一页的预览和选择状态先发布，图片缩略图随后补齐；全文详情和原图按操作读取。卡片仅保留短摘要，搜索和完整复制仍使用全文。
- 历史扫描不再读取非当前页的 PNG，独立后台线程处理历史查询和缩略图。新查询、关闭或隐藏会取消旧加载，迟到结果不会覆盖新页。
- 当前页使用共享快照；流式聚合只保留一份代表内容，减少长重复组和状态更新时的大内容复制。
- 最长边 128 像素的缩略图存入 SQLite，下次直接复用；仅为查看到的图片按需生成，没有启动全库回填。常规大 PNG 逐行缩小，缩略图像素与原生成方式对照一致。
- 修复隐藏窗口的过期重绘等待，避免 UI 线程持续空转；可见搜索框的光标仍正常闪烁，快捷键唤起和事件追踪照常工作。
- 清理本地 Iced 补丁的弃用 channel API 调用；维护文档、优化规划及项目 skills 一并更新。

## 升级与数据

- 可覆盖安装 v0.2.1。升级后默认 `Alt+V` 入口变为快捷面板，完整管理窗口通过上述入口打开。
- 历史和设置仍保存在 `%APPDATA%\Veya\veya.db`，安装和卸载保留用户数据。
- 数据库新增派生缩略图缓存表，不改写原始内容、固定状态、来源置信度或粘贴线索；旧图片首次显示时才生成缓存。每张缓存像素最多 64 KiB，另有 SQLite 开销，数据库可能随浏览图片增长。
- 文件历史保存本地路径，不包含文件本身；图片原始 PNG 和文本全文继续完整保留。

## 验证与性能证据

- 本地格式检查、workspace 检查、115 项测试、release 编译及 Windows GUI 子系统检查通过。
- Windows 11 单屏 100% 缩放的隔离运行验证了快捷面板搜索、选择、实际文本插入、Esc、焦点恢复、全文尾部搜索和完整复制；CPU 修补另验证了可见光标动画及隐藏后再次唤起。
- 发布门禁在一次性 Windows runner 中执行真实安装器：安装 v0.2.1、同路径覆盖到本版、核对已安装程序哈希／版本、注册表和快捷方式，再卸载并确认用户数据保留。此检查验证安装行为，桌面交互由上述本地 Windows 检查提供。
- 固定图片／长文本夹具的开发构建对照中，可操作首屏约 1.88 → 1.27 秒；隐藏后两次唤起约 0.54–0.62 → 0.23–0.24 秒。首页 Private Bytes 约 249.0 → 240.3 MiB（首次生成小图），已有缓存约 225.1 MiB。首次生成后隐藏的内存仍比该基线多约 2.5 MiB。
- 隐藏 CPU 问题在 16 个逻辑处理器的机器上曾持续约 6.1%，接近一核满载；修补 release 的短时重复采样约 0%–0.15%。这些是单机、指定构建和少量场景对照，不是所有机器的性能承诺或长期统计。

## 已知限制

- 普通权限程序向管理员应用发送按键受 Windows 权限限制；自动粘贴不会绕过目标应用的格式支持或系统权限。
- 文件和图片的系统剪贴板类型重放有实际验证；本轮没有宣称其在所有目标应用中实际插入成功。Chrome、记事本和原生 EDIT 的文本路径有验证，最新候选另做原生 EDIT 回归。
- 未覆盖多显示器／不同缩放、其他硬件驱动、长期资源曲线和全部异常场景。
- 后页仍从头扫描轻量历史投影；分页游标复用、粘贴线索增量持久化和平台生命周期整理继续保留在后续规划。
- 安装包未签名，Windows 可能提示未知发布者。
