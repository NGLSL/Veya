# Veya v0.1.0

首个 Windows 公开版本。Veya 在本机记录剪贴板内容和复制来源，并把观察到的粘贴快捷键与当前记录关联，方便查找内容的流转线索。

## 主要功能

- 记录 Unicode 文本、现有文件或文件夹的路径列表，以及支持的位图剪贴板内容；来源进程、窗口和置信度随记录保存。
- 在历史页搜索、按内容类别筛选、按最新或最旧排序，并切换紧凑和详细列表。相同内容的短时间复制可聚合展示，原始事件仍独立保存。
- 查看详情、使用时间线与图片预览；可重新复制原有载荷。文本支持复制为纯文本、打开链接、浏览器搜索和弹窗查看全文。
- 固定记录以跳过自动到期清理，或删除单条、清空全部历史；设置保留期、暂停追踪和排除指定来源应用。历史卡片支持右键菜单。
- 通过托盘和单例窗口使用 Veya；默认 `Alt+V` 显示或隐藏窗口，可在设置中更改或关闭组合键。
- 在设置页手动检查 GitHub Releases，打开仓库和发布页；安装包下载后先校验发布资产提供的 SHA-256，再启动安装。

## 安装与数据

- 这是首个公开安装版本，没有旧版安装包升级路径。安装器需要管理员权限，当前未签名，Windows 可能显示未知发布者。
- 历史和设置保存在 `%APPDATA%\Veya\veya.db`。覆盖安装或卸载不会删除该数据库；需要迁移或清理数据时请自行备份或处理。
- Veya 记录的是粘贴快捷键及当时的前台目标，无法证明目标应用已经成功插入内容。来源和目标可能因窗口切换、权限或系统限制而未知。

## 验证与已知限制

- 发布候选在 Windows 本机通过 `cargo fmt --all -- --check`、`cargo test --locked --workspace`、`cargo check --locked --workspace` 和 NSIS 安装包构建。GitHub 默认分支 CI、标签发布构建、发布资产校验及安装体验以实际发布流程结果为准。
- 文件列表只保存路径，不保存文件本身或剪切意图；重新复制前会检查路径是否存在。虚拟文件和其他 OLE 专有对象尚不支持。
- 图片覆盖 `CF_DIBV5` 和 `CF_DIB`；其他格式或超限数据可能跳过。链接与代码分类根据文本内容推断。
- 完整的跨应用 Windows 实测尚未覆盖 Explorer 文件粘贴、浏览器图片到目标应用、不同图片格式，以及托盘图标在 100%/150%/200% 缩放下的视觉效果。自定义快捷键的焦点、冲突、与其他应用共存和多显示器交互，以及安装、卸载和覆盖安装，也仍需真实桌面验收。
