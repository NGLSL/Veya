# Veya v0.2.7

2026-10-23

降低文本、图片和界面绘图资源的内存占用，减少大文本检索与大图操作时的重复分配。窗口隐藏或最小化后释放绘图资源，重新显示时完整重绘。

## 减少文本与图片的重复副本

- 文本记录、重新复制所用的正文和当前展开详情共享同一份文本；PNG 图片的记录、预览与重新复制复用原始编码缓冲。
- PNG 写入 SQLite 时直接借用已有缓冲，省去写入前的整份复制。文本、文件、图片的载荷类型和固定状态继续保留。

## 控制历史检索的临时占用

- 每次查询只准备一次搜索条件，复用到各条记录。常见 ASCII 大小写匹配分块处理，减少整段正文的小写副本；Unicode 大小写、跨分块匹配和完整正文搜索保持原有规则。
- 历史读取在每批最多 16 条之外，增加约 4 MiB 的正文与文件载荷预算，减少多条大正文同时进入内存的情况。单条超过预算的记录仍完整读取，搜索可继续向后扫描。
- 内存节省伴随部分查询的时间代价：隔离大文本样本中，中文正文与混合大文本库的完整扫描约慢 16%–18%。普通短文本页面的收益主要来自下述字体与绘图资源优化。

## 降低大图转换与重新复制的峰值

- DIB 捕获转换直接借用原始数据，省去封装 BMP 时的整图复制；PNG 转 DIBV5 复用解码后的 RGBA 缓冲。
- 重新复制图片时逐份准备 Windows 缓冲，及时释放中间像素数据，并以完整长度和 SHA-256 核对图片内容。PNG、透明 DIBV5 和白底传统 DIB 三种表示继续保留，全部准备完成后才修改剪贴板。
- 隔离 4K 图片样本中，重新复制前的准备阶段峰值提交量从 177.82 MiB 降到 122.31 MiB，约降低 31%；包含摘要计算的准备耗时从 48.47 ms 增至 92.21 ms。该测量只覆盖发布到系统剪贴板之前的准备阶段，数值用于比较这条图片路径。

## 降低字体与隐藏窗口的占用

- 停止为未启用的等宽字体回退功能提前加载字体和建立脚本索引，保留完整系统字体目录、中文及多语言回退和按需加载。本版随源码携带 cosmic-text 0.12.1 的局部修正。
- SVG 图标和 SVG 文字共享进程内的系统字体目录，避免重建绘图缓存时反复扫描字体。
- 管理窗口和快捷窗口隐藏、最小化后释放绘图表面、像素遮罩及绘图缓存，保留界面状态。恢复时按当前尺寸与缩放重新创建资源并完整绘制首帧。
- 在隔离的 25 条普通文本原生窗口样本中，每种场景各运行 5 次，Private Bytes 中位数如下：

| 场景 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 管理窗口 100%，显示时 | 25.48 MiB | 12.48 MiB |
| 管理窗口 100%，隐藏时 | 25.48 MiB | 8.67 MiB |
| 管理窗口 200%，隐藏时 | 35.96 MiB | 8.85 MiB |

释放缓存会增加恢复绘图的开销：管理窗口隐藏后重新显示，100% 的画面就绪中位数从 3.62 ms 增至 20.75 ms，200% 从 3.61 ms 增至 43.17 ms；快捷窗口优化后分别为 9.84 ms 和 16.65 ms。这是绘制完成、即将提交画面的 render-ready 时间，100%／200% 指程序绘制缩放；完整应用的端到端显示延迟需要另行测量。

## 升级与数据

- 可覆盖安装旧版，历史和设置继续保存在 `%APPDATA%\Veya\veya.db`；安装与卸载保留用户数据，本版没有数据库迁移。
- 已有历史记录可直接继续使用，无需重新采集。内存中的共享与缓冲调整保持数据库格式不变。

## 验证

- 本地格式检查、锁定依赖的 workspace 检查、debug 构建、release 安装包构建及现有 129 项测试通过；版本更新后重新通过格式检查、现有测试、workspace 检查和安装包构建。没有新增测试用例。
- 字体与窗口资源比较在版本号更新前的优化候选上完成，包含 80 个独立 release 采样进程，覆盖管理／快捷窗口、100%／200%、真实原生窗口生命周期和离屏分阶段绘图。字体目录、默认中文字体族、多语言画面以及隐藏／最小化后恢复的画面摘要前后一致；隐藏期间改变尺寸和程序缩放后恢复也通过核对。
- 图片与搜索另有同机隔离源码路径对照。上述采样均使用合成数据或隔离状态，未运行日常数据库、业务 worker、全局热键及目标应用粘贴流程；表格数值用于比较对应路径的改动。
- 发布门禁包括全新 Windows runner 上的现有测试、release 安装包构建、安装、覆盖升级、卸载与用户数据保留检查，结果见对应 CI／Release 工作流。
- 本次未将新版本安装到日常使用环境；完整 Alt+V 操作、QQ 等目标应用中的实际粘贴，以及真实跨显示器 DPI 迁移仍待人工验收。

## 使用条件

- 隐藏时释放绘图缓存，以较低的后台占用换取恢复时的一次重绘；高缩放下需要重建的像素缓冲更大。
- 安装包未签名，Windows 可能提示未知发布者。
