# 01：窗口生命周期与统一唤起

Status: ready-for-human
Blocked by: none

## 要做什么

把托盘“打开窗口”从空分支接到实际唤起；统一托盘打开/设置、单例二次启动及后续热键的显示、恢复、聚焦行为。关闭按钮改为隐藏到托盘，显式“退出”结束进程。保留已有鼠标所在显示器与可见工作区定位规则，恢复时防止窗口落在已断开的显示器外。托盘不可用时提供可理解且可退出的退路。

## 验收

- 最小化与关闭后，托盘打开和重复启动均恢复同一个主窗口；设置命令恢复窗口并显示设置页。已显示时唤起仅聚焦，用户手动移动后的窗口位置得到尊重。
- 关闭到托盘不停止跟踪；托盘退出结束进程，单例守卫随之释放，再次启动正常。
- 拔插显示器、改变缩放或分辨率后恢复，窗口仍位于可见工作区且交互区域可用；托盘创建失败时不会遗留不可恢复的后台进程。
- 在 Windows 真机按上述路径实测，记录窗口可见性、焦点和进程状态；纯逻辑路由有必要时加最少测试。

## 实现记录

托盘命令、二次启动和热键已接到同一窗口恢复任务。隔离进程中验证了第二次启动恢复最小化窗口且只保留一个进程；托盘菜单和多显示器仍需解锁桌面手动验收。
