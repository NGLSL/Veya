# 03：快捷键设置、冲突反馈与端到端验收

Status: ready-for-human
Blocked by: 02

## 要做什么

在设置页展示当前唤起组合及其实际注册状态，支持更换或关闭组合并持久化。更换失败时保留旧可用组合；若无可用组合，展示托盘和重复启动仍能恢复窗口的提示。统一核对托盘“打开窗口／设置／退出”、单例激活和热键的用户可见行为。

## 验收

- 改键后新组合生效、旧组合释放；重启后使用保存的组合。禁用后无全局热键，托盘和重复启动仍能唤起。
- 冲突或无效组合有可见反馈，设置页显示的是实际注册结果而非仅保存的字符串；更换失败不丢掉原有可用绑定。
- 在 Windows 真机与 Kite 同时运行，覆盖不同分辨率/缩放和显示器变更，并抽查常用应用原有的 `Alt+V` 菜单行为；分别记录自动测试、真实按键、托盘、窗口和退出清理结果。

## 实现记录

设置页已显示当前组合、注册状态和错误，支持录制、默认、关闭；录制时移除排除应用输入框并在窗口失焦时取消。组合的解析/持久化测试已通过；输入焦点、冲突界面和不同显示器的真实交互仍需解锁桌面验收。
