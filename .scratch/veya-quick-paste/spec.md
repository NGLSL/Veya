# 快捷粘贴面板

## 目标与范围

把日常操作收敛为「正在输入 → Alt+V → 选择历史 → Enter 或点击 → 原应用继续输入」。默认热键打开约 440×580 的轻量面板，最近记录优先，保留完整历史搜索。托盘和管理入口继续提供大窗口，用于管理记录、设置和查看来源／使用线索。

当前需求授权实现与验证；发布和部署不包含在本次范围。详细验收见 [01](issues/01-quick-paste.md)。

## 交互契约

- 打开面板保存唤起前的目标窗口；初始化最近优先的查询和明确选中项。上下键移动选择；直接输入可搜索完整历史；Enter 与点击执行相同操作。
- 文本、现有本地文件列表、PNG-backed 图片均按原类型重放，不能将文件或图片降为显示文本。
- 先确认剪贴板写入成功，并检查对应剪贴板序号，再隐藏面板、恢复目标窗口并发送 Ctrl+V。写入失败、剪贴板被其他应用覆盖或目标无法恢复时，显示可理解的失败状态，不能粘贴旧内容。
- Esc 或失焦关闭面板；取消后能立即回到原应用继续输入。管理窗口关闭／托盘行为继续遵守现有窗口生命周期。
- 重放绑定原始 record，不新增 raw copy record；使用线索只代表观察到粘贴尝试，不宣称目标应用已插入内容。保留来源 confidence、pin 和聚合历史与原始记录的区分。
- 临时面板查询和选中态与管理窗口状态明确隔离；回到管理入口恢复原管理查询和窗口大小。

## 分层

Iced 的窗口模式、键盘和选中态归 desktop app；重放读取和结果协调归 worker；剪贴板写入、目标窗口恢复和输入注入归 windows。core 只维护事件与原记录关联语义。view 不查询 Win32 或 SQLite。

## 验证

复用现有自动检查，覆盖消息路由、选中／退出行为、typed replay 和内部重放关联。实际 Windows 验证应覆盖记事本、浏览器输入框、常用编辑器中的唤起、选择、取消、目标恢复和文本粘贴；图片和文件另选支持其类型的目标。还需验证剪贴板竞争和失败不误粘。

实际运行证据放在 [validation](validation/)；当前运行验证进行中，已有脚本或源码测试不能替代交互验收。未取得证据的组合须明确标记未验证。

## 与性能规划的关系

面板使用当前页共享快照，隐藏后释放历史页和展开图片。进一步的 metadata 投影、游标复用和存储增量写入列入 [整体代码与内存规划](../veya-code-optimization/spec.md)，不能因优化缩小搜索范围或损失内容类型。
