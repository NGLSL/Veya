# 02：历史记录排序菜单

Status: ready-for-agent
Blocked by: none

## 要做什么

把静态“最新优先”容器改为可操作菜单，提供“最新优先／最旧优先”。排序只改变显示顺序，不改变原始事件、聚合结果或存储顺序。默认最新优先；用时间及序列号决定稳定的同时间顺序。

## 验收

- 点击可展开菜单并切换两种顺序，当前选项与按钮文案一致；再次打开菜单可见选中状态。
- 搜索、内容筛选和排序可以组合使用；切换排序后保持仍存在的选中记录及其详情，记录不再存在时选中当前列表首项。
- 新记录到来后仍遵守当前顺序；滚动位置不应跳到无关内容。
- 用相同时间戳、不同序列号及聚合记录验证确定性；Windows 运行界面实际点击验证。
