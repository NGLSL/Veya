# 05：文件列表捕获、展示与重新复制

Status: ready-for-agent
Blocked by: none

## 要做什么

依据 04 的载荷契约，先支持现有本地文件/文件夹列表的 Windows 剪贴板格式。历史卡片显示文件图标、名称和数量；详情显示完整路径及来源/使用记录；可按“文件”筛选并重新复制文件列表。虚拟文件/OLE 对象留到后续。

## 验收

- 从 Explorer 复制单个文件、多个文件、文件夹后各生成正确的一条文件记录；粘贴触发仍关联同一记录，重启可恢复。
- 重新复制后可在 Explorer 粘贴，且 Veya 自身写入不产生重复历史；原文件已移动或删除时给出准确提示。
- 文件列表与纯文本路径、带 URL 的文本互不误判；超限/不支持的格式安全跳过。
- 在 Windows 真实 Explorer → Veya → Explorer 路径验证；核心/存储测试覆盖列表序列化和重放。

## Implementation status（2026-09-23）

`CF_HDROP` 捕获、路径列表持久化、文件筛选、详情和按复制意图重放已接入。隔离 Windows 实例用 `SetFileDropList` 验证单个文件及 3 项文件/文件夹列表，重启后仍可查看；重新复制时系统 `FileDrop` 返回 3 个存在的路径，且没有新增 Veya 自身记录。真实 Explorer 复制/粘贴和失效路径的界面提示尚待验收。
