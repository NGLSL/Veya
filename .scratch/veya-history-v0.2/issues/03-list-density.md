# 03：紧凑／详细列表视图

Status: ready-for-agent
Blocked by: none

## 要做什么

右侧列表图标按用户选择切换“紧凑／详细列表”。详细模式保留当前内容预览、来源和去向摘要；紧凑模式减少行高，只保留类型图标、单行预览、来源和相对时间。默认详细模式，本次运行中记住选择，不新增持久化设置。

## 验收

- 按钮可点击，有明确的当前模式提示；切换后行高和字段确实变化，记录数量、排序与筛选结果不变。
- 两种模式都能选中、查看详情和复制记录；长文本省略且不撑破列表；键盘访问与焦点不丢失。
- 在默认 1080×700 窗口、含长文本和多条记录的 Windows 运行界面检查滚动与布局。
