# 07：固定记录与到期清理豁免

Status: ready-for-agent
Blocked by: none

## 要做什么

为历史记录添加持久化固定状态、固定/取消固定动作和“已固定”筛选。固定适用于文本、文件、图片；按用户选择，固定记录跳过自动到期清理，直到取消固定或手动删除。用户明确执行“清空全部历史”仍删除固定记录，清空确认文案应说明这一点。

固定状态属于原始记录。用户在聚合历史卡片上操作时，对该卡片当时包含的全部原始序列执行固定/取消固定；聚合不得混合固定与未固定原始记录。后续同内容的新复制默认未固定，不自动继承先前卡片的固定状态。

## 验收

- 固定状态、图标与筛选立即同步，重启后仍在；取消固定后恢复正常的保留期规则。
- 到期清理保留固定记录并清理同龄未固定记录；手动删除和确认后的清空全部历史都能删除固定记录。
- 固定状态不会改变复制/粘贴流的身份，也不会被聚合或重新复制意外清掉。
- 两次短时间相同复制先聚合成一张卡片，再固定时两个原始序列都保留；之后同内容新复制仍是未固定记录且不会被折进已固定卡片。取消固定后，超过保留期的记录按常规清理规则处理。
- 存储与清理规则用测试覆盖，并在 Windows UI 实际点选、重启、清理验证。

## Implementation status（2026-09-23）

固定状态随 04 的 schema 迁移落地，core 聚合、持久化与到期清理测试已通过。隔离 Windows 实例已验证在图片详情固定、数据库 `pinned=1`、重启后仍有图标，以及“已固定”与文件/图片分类组合筛选。文本/文件固定、真实到期运行、手动删除固定记录和确认清空全部历史的 UI 流程仍待验收。

2026-09-23 后续：历史卡片在详细和紧凑列表中支持鼠标位置弹出的独立右键菜单，复用原有卡片级固定/删除命令。隔离 Windows 实例实测右键取消固定后数据库 `pinned=0`；弹出菜单固定文件记录后数据库 `pinned=1`，再从菜单删除该固定记录，其他记录仍在。Esc 或菜单外左键可收起；清空确认仍按上面的验收项跟踪。
