# 06：图片捕获、预览与重新复制

Status: ready-for-agent
Blocked by: none

## 要做什么

依据 04 的编码与上限决定，支持 Windows 常见图片剪贴板格式并保存可重启恢复的图片载荷。历史卡片与详情显示真实缩略图和尺寸/大小；可按“图片”筛选并重新复制图片。不得把网页链接文本或图片文件路径当成图片像素。

## 验收

- 从截图工具和至少一个浏览器复制图片，可形成图片记录，重启后预览仍可见；文本+图片并存的同一次剪贴板变更只生成一条正确类型记录。
- 重新复制后能在支持图片粘贴的应用中粘贴；Veya 自身写入不重复记录。粘贴触发关联保持准确。
- 大图、损坏数据和不支持格式遵守 04 的上限及跳过规则，不阻塞剪贴板监听线程。
- 在真实 Windows 应用链路验证上述行为，测试覆盖编解码、持久化和类型筛选。

## Implementation status（2026-09-23）

`CF_DIBV5`/`CF_DIB` 捕获、PNG 持久化、图片筛选、真实缩略图及 `CF_DIBV5` 回拷已接入。隔离 Windows 实例用 3×2 像素的 .NET 图片验证捕获、重启恢复和回拷为系统 Bitmap，且不新增 Veya 自身记录；运行中也观察到 Snipaste 来源的图片记录。浏览器复制图片、真实目标粘贴及损坏/超限样本的应用链路尚待验收。
