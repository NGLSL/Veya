# 01：让内容筛选只显示真实匹配项

Status: ready-for-agent
Blocked by: none

## 要做什么

修复 `Filter::File | Filter::Image | Filter::Pinned => true` 的误导行为。保留现有“文本／链接／代码”筛选，明确普通文本、链接、代码的互斥归类；尚未交付的三个标签显示为不可用，直到各自数据能力上线。筛选后无结果应显示“该分类暂无记录”，与全局无记录和搜索无结果区分。

## 验收

- 代码片段在“代码”中出现，在“文本／链接”中不出现；URL 和普通文本各在对应分类出现。搜索与筛选叠加后结果正确。
- 文件、图片、已固定在相应实现前无法选中，不会显示全部文本记录；禁用状态仍符合当前设计图。
- 复制一个看似文件路径的纯文本，仍归为文本；重启后分类不变。
- 针对分类判定和筛选交集补最少必要测试，并在 Windows 历史页实际点选核对。

## Comments

- 2026-09-22：已实现真实分类筛选；文件、图片、已固定标签在相应数据能力上线前禁用。测试覆盖文本、链接、代码、路径文本和搜索交集。Windows 初始界面已查看；自动点击因前台焦点被其他应用抢占而未完成，仍需人工点击验收。
- 2026-09-23：文件、图片载荷和固定状态已接入，三个标签已启用。隔离 Windows 实例实际点选文件、图片及“已固定”与二者的组合；文件无固定记录时显示分类空状态，图片固定记录可见。纯文本路径归类仍由自动测试覆盖。
